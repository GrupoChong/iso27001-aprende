# ISO 27001 Aprende

Este repositorio solo publica las versiones de la app de estudio para Android (curso ISO/IEC 27001:2022 – 27002:2022).

- Descarga: pestaña **Releases**, archivo `ISO27001-Aprende-<versión>.apk`.
- Desde la versión 1.5.0 la app revisa sola si hay una versión nueva y pregunta antes de instalarla; el progreso se conserva.
- Cada release incluye `version.json` con el número de versión y la huella SHA-256 de la APK, que la app verifica antes de instalar.
